# 🐦 Flappy Naruto

**Flappy Naruto** is a simple 2D arcade game inspired by the classic Flappy Bird. In this version, the player controls **Naruto** and tries to fly through obstacles featuring **Akatsuki-themed symbols**.

The game is currently **under development**, with basic player movement, obstacle movement, scoring, and sound implemented. The player death and game-over system are still being worked on.

## 🎮 Features

- Naruto as the playable character
- Akatsuki-themed obstacles
- Flappy Bird-style gameplay
- Player jump/flying movement
- Moving obstacles
- Score system
- Jump sound effect
- Simple 2D gameplay

## 🚧 Work in Progress

The following features are still being developed:

- Player death/collision system
- Game Over screen
- Restart functionality
- Improved scoring system
- Additional sounds and effects
- Final UI and game polish

## 🛠️ Built With

- Unity
- C#
- 2D Game Development

## 🎯 Goal

The main goal of this project is to create a fun Naruto-themed version of a simple arcade game while learning Unity, C# scripting, player movement, collision detection, scoring, sound effects, and game development.
